An office coffee machine might serve forty people before lunch, and every one of them reacts differently when an error code appears. One person ignores it, another empties everything in sight, a third switches the machine off and on and walks away. Multiply that by a rental contract and a service hotline, and you get wasted callouts, disputed invoices and machines that fail faster than they should. A little etiquette fixes most of it.

## The core problem with shared machines

Errors on a domestic machine get diagnosed by the person who caused them. In a shared kitchen, ownership disappears: nobody saw the first code, the display has already scrolled on, and the next user only knows the machine "doesn't work". Rental machines add a contractual layer, because who is allowed to reset or open something can determine who pays. The goal of good etiquette is simple: **every code gets seen, recorded and routed to the right level exactly once**.

## Who resets what

Split responsibilities into three tiers:

- **Anyone in the office** may do the visible, mechanical fixes: refill and reseat the water tank, empty the drip tray, and empty the grounds container — on machines like the DeLonghi Magnifica Dinamica, [emptying the grounds container](https://codefixcoffee.com/delonghi/magnifica-dinamica/insert-grounds-container-empty-grounds-container/) clears the related prompt without any menu work.
- **One nominated machine champion** handles everything involving menus: acknowledging descaling prompts, resetting cup counters, checking maintenance status and running cleaning cycles when due. Choose one named person, not "whoever is nearest".
- **The rental provider or service partner** handles anything behind panels: internal blockages, grinder faults and recurring codes that survive a proper clean. Opening the machine yourself can void the service terms.

## Read the log before calling service

The first visible error is often not the root cause, so gather context before anyone phones the hotline:

1. Photograph the display with the code still visible.
2. Note what the machine was doing when the code appeared — grinding, brewing, steaming or idle overnight.
3. Check whether the code has appeared before: recurring patterns, like a [fill-water-tank warning despite a full Jura tank](https://codefixcoffee.com/jura/automatic-machines/fill-water-tank-tank-is-full/), point towards a sensor or logic issue rather than user error.
4. Read the machine's own counters where available. Many [Jura](https://codefixcoffee.com/jura/) automatic machines can show maintenance and interval information, and app-connected machines keep event histories you can scroll through.
5. Write everything down for the technician: date and time, code, drinks served since the last clean, and the water hardness setting.

Generic codes deserve extra context. A broad fault such as [error 20 on Philips Saeco espresso machines](https://codefixcoffee.com/philips-saeco/espresso-machines/error-20/) can have more than one root cause, so the story around the code is what makes the service call useful instead of speculative.

## Cost responsibility

Rental contracts vary, but the split usually follows one logic — normal wear versus misuse:

- **The provider covers** component failures under normal use, electronics faults and parts included in the service agreement.
- **The customer covers** consumables and cleaning — outsourced descaling typically costs **€60-€120** per visit — plus damage from misuse, such as foreign objects in the grinder or milk systems left to rot over a long weekend.
- **The disputed middle ground** is limescale damage from skipped descaling cycles. This is where your written maintenance log pays for itself.
- **Callout fees**: if a technician arrives to find the only fault was an unfilled tank or an unemptied grounds container, the visit is commonly billed at **€90-€150**.

For office-owned machines, budget an annual professional service at **€120-€200** and treat anything beyond that as a repair-versus-replace decision.

## Prevention routines in shared settings

- Run a **weekly rota**: grounds container, drip tray, water tank refresh and a wipe-down. Ten minutes, rotating between colleagues.
- Keep a **laminated card** by the machine listing the three codes most likely to appear and the single action each one needs.
- Maintain a **log book**, paper or shared, recording every code, its date and the action taken. It doubles as evidence in billing disputes.
- Put filters and cleaning products on a standing order so nobody "forgets" to reorder.
- Extend the same protocol to other shared kitchen equipment — connected appliances such as dishwashers throw communication errors like [GE's error 888](https://codefixcoffee.com/ge/dishwasher/888/) that benefit from exactly the same note-it-first culture.

For care schedules you can adapt into an office routine, manufacturer resources such as [delonghi.com](https://www.delonghi.com) and [philips.com](https://www.philips.com) publish maintenance guidance for their automatic machines.

Clear etiquette is cheaper than any repair: it shortens downtime, keeps invoices undisputed and stops small codes from snowballing into real faults.
