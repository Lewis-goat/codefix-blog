"De'Longhi descale light that won't go out"

2026-11-04

You ran the descaler, you waited, you rinsed — and the descale light is still on. A De'Longhi that keeps its descale reminder lit after you have descaled is not being stubborn; it is doing bookkeeping. The machine only clears the reminder when it has seen a full descale cycle, rinse phase included, run from the descale menu with the spout fitted. Anything less and, as far as the descale counter is concerned, you never descaled at all. The descale light stays on after descaling reference covers this for Magnifica, Dinamica and PrimaDonna machines; here is the short version.

The full-cycle rule

The reminder is driven by the machine's own count of the cycle, and three honest-looking shortcuts all fail to register:

  • Stopping early. The cycle has a descale phase and a rinse phase; if you switch off before the rinse finishes, the cycle never completes.
  • Descaling by hand. Pouring descaler into the tank and pulling water through yourself may clean parts of the circuit, but the machine never sees a descale programme, so the counter never advances.
  • Missing spout. The hot-water spout has to be fitted before you start, because the cycle dispenses through it.

Running it so it counts

  1. Fit the hot-water spout and put a large bowl under the outlet.
  2. Start the descale from the machine's descale menu — not by improvising with the tank.
  3. Let both phases finish completely: the descale phase and the rinse. Expect it to take a while and need plenty of bowl capacity; that is the process working, not a malfunction.

The filter setting mismatch

De'Longhi machines track whether a water filter is fitted, and the recorded setting has to match reality. A machine whose menu says a filter is fitted when there is not one — or the reverse — is the second documented reason the descale light stays on. Go into the settings and check that the water-filter entry matches what is actually inside the tank. If you recently added or removed a filter and the light appeared around then, this is almost certainly your answer.

The scaled flow sensor

If the cycle was genuinely run in full and the filter setting is correct, the remaining suspect is the flow sensor — the component that counts water moving through the machine. Scale coating the sensor means the machine cannot count the descale cycle's flow, so the cycle never registers as complete however carefully you ran it.

The fix sounds circular but it works: run a second descale. The first properly-run programme will have passed descaler over the sensor, and the second cycle often then counts normally and clears the light. Descaler costs around €10 a bottle, which makes this the cheapest possible second attempt.

Scale throws other messages too

A stubborn descale light is the least dramatic way scale announces itself. On De'Longhi machines older than a year, most Ground Too Fine, Adjust Mill messages are really scale, not a grind problem: the pump hits its pressure limit because scale has narrowed the heater or infuser circuit, and a descale is the documented fix. Clearing the descale regime properly often takes those messages with it.

The same logic elsewhere

The let-it-finish rule is not a De'Longhi quirk. Jura's cleaning programme for Error 8, the brew-group code, only counts if it runs uninterrupted to the end — an interrupted maintenance cycle is, to the machine, a cycle that never happened. Scale is likewise the first listed step for several Jura valve and heater faults, and the Jura section covers those code by code. The full set of De'Longhi messages — the words on the display and the hidden numeric codes behind them — is on the De'Longhi hub.

What it costs and when to stop

  • Descaler: around €10 per bottle.
  • Everything else: usually nothing. This fault is rated low-severity and easy for DIY.
  • If two full cycles with the correct filter setting still leave the light on, the flow sensor is the part to ask a technician about — it is not an expensive part, but it sits inside the machine.

The boring explanation is nearly always the right one: the last descale never fully counted. Run it from the menu, with the spout on, both phases to the end — then check the filter setting, and only then reach for a second bottle.
